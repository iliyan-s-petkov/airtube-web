# D4 — accessibility and responsive pass, 2026-09-03

Measured against a local server (`go run ./cmd/airbg serve`) with Playwright.
Lighthouse is not used as the evidence here: it cannot see a focus ring, which
is the half of #250 that matters most.

## Contrast (WCAG AA)

Every element carrying its own text node was measured against its nearest
painted ancestor background, at its real font size and weight, with the 3∶1
large-text threshold applied where it qualifies.

- Before: **4 failures**, all in the footer — `--meta` on `--surface` at 12px
  measures **3.02∶1** against a 4.5 floor. Two attribution lines, the update
  line and its `<time>`.
- After: **0 failures**.

The footer now takes `--fg-2`. DESIGN.md §5.5 asks for `--meta` there, but the
same document already ruled that a contrast floor outranks a colour convention
when it made the identical call for map labels on `--surface-2`. `--fg-2` is
still visibly quieter than body ink.

## Colour is not the only channel

The map legend carries, per band, a **name** and a **numeric range** —
*Добро ≤ 5 · Задоволително 5–10 · Умерено 10–20 · Лошо 20–25 · Много лошо
25–50 · Изключително лошо > 50*, plus *Недостатъчно данни* outside the ramp and
a tier line stating what a dot aggregates. 7 rows, 7 labels, 6 ranges.

A first pass reported this as missing. That was a **stale local build**, not a
defect: `internal/web/dist` had been built before the legend work landed, and
`dist/` is a build artefact (only `.keep` is tracked), so production builds it
fresh in Docker. Rebuilding locally showed the legend intact. Recorded because
the symptom — legend title with no rows — looks exactly like a real bug.

## The map is now a named region

It was an unlabelled region announcing only "Map". It now carries
`role="region"`, `aria-label` from the catalogue (`map.label`), and
`aria-describedby` pointing at a one-sentence alternative (`map.text_alternative`)
that names the province list below as carrying the same readings in text. The
list was already the no-JS fallback and the crawlable content; the two are now
connected rather than merely both present.

## Keyboard walkthrough

16 tab stops, in document order, every one with a visible focus ring
(`box-shadow`, the Carbon double ring):

wordmark → Карта → Райони → English → the seven metric buttons → Намери ме →
the map canvas → the province links.

- **Missing focus rings: none.**
- The metric switcher is operable from the keyboard: focus a button, press
  Enter, `aria-pressed` moves ПМ2.5 → ПМ10 and the map repaints.
- The map canvas is focusable, so the basemap's own keyboard controls are
  reachable.

The three D0 responsive failures — header wrapping to two lines, the language
pair splitting, the metric buttons wrapping to three rows — are all clear at
every viewport. The map holds 926∶382 at 1440 and 2304; at 390 and 768 it is
taller than the fit, which §1 states is the safe direction.
