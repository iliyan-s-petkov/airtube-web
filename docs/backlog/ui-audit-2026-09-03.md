## D0 design defects, re-checked

- **No visual identity** — tokens are bound: `--accent #0f62fe`, `--fg #161616`,
  IBM Plex Sans, `--measure` 60rem / `--frame` 78rem. Resolved.
- **No legend for the dot colours** — `.map-legend` is present on the home map.
  Resolved.
- **Header breaks at 390** — was two lines; the wordmark was an ordinary flex
  child squeezed to 62px. It no longer shrinks, so the masthead stays one line
  (§5.1). Resolved. The language pair no longer splits either.
- **Inconsistent layout widths** — three widths remain, and that is now the
  contract rather than a defect: prose sits at `--measure` (960px) and data at
  `--frame` (1248px), which is §4.1's two-container rule. The map is 1184 =
  frame minus the gutter, so it fills its container.
- **Over-weight four-paragraph footer** — not re-measured in this pass; still
  open.
- **Areas list is a flat directory** — unchanged; the ranked, value-bearing view
  #249 specifies is not built yet.

## Corrections to my own reading

A first pass flagged `fieldset`/`legend` on the metric switcher as an outstanding
D0 defect. That was wrong twice over: the switcher is already styled buttons
carrying `aria-pressed`, and DESIGN.md §5.6 explicitly requires the fieldset to
*stay* — it is the correct grouping semantics for a radio set and what a screen
reader needs. Replacing it with divs is listed as an anti-pattern.
