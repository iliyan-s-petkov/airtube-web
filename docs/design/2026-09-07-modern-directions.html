airbg.org — three modernisation directions

Same content in all three: masthead, metric switcher, map with chrome and key, province table. Air-quality band colours are identical everywhere — they carry regulated meaning and are not a style choice. What differs is the interface around them.

A · Carbon, sharpened

Modernise by hierarchy, not decoration. Keeps every current kit ruling — square corners, no card shadows, no 700 weight, depth by background layering. Gains come from a bigger type scale, real whitespace and lighter rules. Kit change: none structural.

B · Soft surfaces

The conventional 2026 app look. Tinted page, white cards with radius and soft shadow, a segmented pill for metrics, floating translucent map chrome. Kit change: overturns §4.4 (“no shadows on cards”) and --radius: 0 — the two rulings that currently define the kit's character.

C · Editorial

Modern the way a newsroom data page is modern. Large light display type, hairline rules, no boxes, the number itself is the loudest thing on the page. Kit change: type scale and layout only — square corners and no-shadow survive, so it is closer to the kit's stated intent than B is.
